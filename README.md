# 日程表

## 下载与安装

请从 [GitHub Releases](https://github.com/Nekobenzene/warm-calendar/releases/latest) 下载最新版本，无需在源码或本地 `dist` 中挑选安装包。

- Windows：下载 `warm-calendar-版本-windows-x64-setup.exe`，运行安装向导。升级前先从托盘退出日程表；日程和连接数据保留。
- Android：下载 `warm-calendar-版本-android.apk`，直接覆盖安装；不要先卸载。要求 Android 7.0 或更新版本。
- 每个 Release 附带 `SHA256SUMS.txt`，可核对下载完整性。Windows 当前尚无受信任代码签名，APK 使用持续保留的发布密钥。

源码、文档和测试存入仓库；安装包仅发布到 Releases，密钥、个人日程库、工具缓存和本机验证记录不提交。发布步骤见 [RELEASING.md](RELEASING.md)。

Flutter / Dart 功能原型，采用 quiet-tool-ui：暖浅色、中文界面，桌面左侧导航、手机底部导航。Windows、Android 与 Web 共用界面和业务代码；提供 Web 预览、Windows 桌面构建及 Android APK。用户已反馈当前Windows环境系统通知恢复正常，智能应用控制开启时的发布签名兼容仍待处理，详见 HANDOFF.md。

## 已实现

当前版本为 **0.6.0**，发布说明见 [releases/0.6.0.md](releases/0.6.0.md)。新增三种重复模式及独立节点编辑、七类假期筛选、日历选中删除、点型线标签与两小时分度，以及自动检查更新、下载进度和安装入口。正式版沿用原数据及应用身份；之前的独立预览可并存，其数据不自动迁入正式版。构建及验证记录见HANDOFF.md。

- 首页：设备时间与 UTC、公历农历、星期、节日节气；下一项固定显示最近一条未来未完成日程、开始时间和倒计时。下方四状态列表及计数仅当天，跨日相交即计入。右侧三点菜单编辑、完成/恢复、删除，删除需确认，右下提示停留1.5秒并有进出动效。
- 日历：桌面周/月、手机日/周/月。周视图固定七天宽并支持连续横滑、纵向滚动；箭头/今天缓动到完整周，月视图横滑翻页。手机七列色块，点击后显示底部详情和拖动/编辑菜单。选中后可移动和调上下边界；防误触锁、网格吸附、Shift滚轮与手机捏合缩放。颜色、透明度、重叠连续分列和红/黄虚线保留。
- 日程：全天、跨日、零时长时间点、备注、提醒、搜索、四状态筛选及五种正倒序排序。不重复、重复日程、重复周期三种模式；节点独立设置时间、提醒、颜色、备注及七类假期筛选。各次独立处理，删除和改期可选本次或整个系列。可选过期自动完成，默认关闭。
- 紧凑创建表单：宽度660，开始时间右侧重复按钮、结束时间右侧提醒按钮；常规桌面一页完成。全天右侧颜色按钮打开独立调色窗，提供预设、色板/色环/HSL、HEX/RGBA/RGB/HSLA及不透明度。复杂重复规则单独配置，小屏保留必要滚动。
- 提醒：每次日程最多12条，多选预设或自定义提前分钟/小时/天，单项与全局提示音开关。重复日程各次独立提醒；兼容旧单次提醒和旧备份。
- 设置：设备名、周起始日、24小时制、农历、逾期自动完成、网格吸附、提醒、托盘、开机启动、JSON备份。手机分类平铺纵向滚动。设备名联网后更新对端列表，逾期自动完成开关跨设备同步；通知等其他偏好各端独立。
- 外观：主题预置色、色相和有界饱和度，自动协调界面色阶与文字对比度；本机图片背景，主界面和侧栏/手机底栏独立调模糊与图片明显程度，可清除恢复默认。
- 日历交互：最细1分钟分度，1/5/60分钟线分层；时间轴与外层页面交接滚动，边界阴影及手机轻微拉伸。移动和边界均可跨日，目标直接铺半透明预览，原块只留选中框。手机滚动保持选中，详情展开时将日程滚到可见处。
- 日历数据：内置2025、2026年假期；联网每天检查当年前后一年，可手动更新并缓存。农历、节气与常见节日离线计算覆盖1901—2099年。
- 本地 SQLite：刷新后保留数据；备份事务合并，相同 ID 按修改时间保留新版本；保留版本、删除标记和待同步队列。
- 链接：Windows 启动本机同步服务、120秒自动刷新及手动刷新二维码，Android 扫码后经电脑核对确认。同步日程及状态、重复规则、颜色、提醒与删除，离线队列重连补传。当前交付范围为本机 / 同一局域网，详见 LINKING.md。
- 手机使用底部导航、紧凑首页、七列周视图、平铺设置及并排表单。安装标识让重连复用原设备，普通断网返回后自动续连，主动解绑需重新扫码。Android原生通知支持通知音量、声音／振动及精确提醒权限，说明见 ANDROID.md。

## 打开预览

在项目目录执行：

```powershell
.\scripts\start-prototype.ps1
```

访问 <http://127.0.0.1:4173>。使用固定端口以保留该站点的本地数据库；其他浏览器、域名或端口拥有各自存储。清除站点数据会删除网页版日程，请先导出备份。需要 Node.js，预览使用已生成的 `build/web`，字体和渲染资源均随构建打包。

## 当前范围

- Web提醒仅在页面运行期间检查。Windows系统队列安排未来30天最近512条，Android为最近128条，前台每分钟续排；排定失败时运行期间回退为即时系统通知，并提供错误详情。Android后台同步后也更新提醒，未允许精确提醒时可能延迟。用户反馈当前Windows环境通知恢复；Android横幅、声音、振动及厂商后台策略尚待真机验收。
- 已实现无需账号的配对同步；未部署公网服务，暂不支持各自在不同网络下同步。Android 前台约2秒轮询，后台15分钟周期任务可被系统推迟。尚未实现系统日历互通和并发冲突处理。
- 重复以停止日期或循环轮数结束，单组最多96个节点、10000个展开实例，节点时长不能超过重复周期（月按最短28天校验）。按设备本地日历展开，暂不支持固定时区和跨时区旅行规则。
- 中国大陆法定节假日和调休内置2025、2026年，可自动/手动更新已公布数据。2030、2050年放假调休尚未公布，不能提前填入；普通日期、农历、节气和常见节日不受此限制。未知年份明确提示未收录，涉及假期筛选的重复规则仍会校验。
- 日期录入范围 1901—2099 年。具体时间按 UTC 保存、按设备时区显示；全天日程保存日期而不转 UTC。

## 结构

```text
lib/domain/       日程模型、状态、备份格式、历法与假期数据
lib/data/         SQLite 仓库和同步队列
lib/sync/         配对、凭据安全存储、游标同步、后台任务和本机服务启动
lib/platform/     通知适配接口
lib/ui/           五个页面、日程表单、共享组件和主题
sync-server/      Node.js 24 HTTP + SQLite 同步服务及测试
lib/app_controller.dart  页面共享状态与提醒检查
assets/holidays/  带来源与年份的放假数据
```

界面约定见 `DESIGN.md`，交接与继续开发说明见 `HANDOFF.md`，开源依赖与数据来源见 `THIRD_PARTY.md`。

Windows 构建：`.\scripts\build-desktop.ps1`。Android 构建：`.\scripts\build-android.ps1`，签名密钥保存在忽略的 `.tooling/signing/`，升级需要保留同一密钥；构建与连接步骤见 `LINKING.md`。

Windows安装向导：完成桌面构建后运行`.\scripts\build-installer.ps1`，生成`dist/日程表-Setup-0.5.0-x64.exe`。支持自定义安装目录、桌面／开始菜单快捷方式及位置、开机自启动、安装后立即运行。升级和卸载保留日程数据。当前无受信任Windows签名，详情见`SIGNING.md`。
