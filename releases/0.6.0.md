# 日程表 0.6.0

## 下载与升级

- Windows x64：`warm-calendar-0.6.0-windows-x64-setup.exe`。沿用原安装目录、数据和设备连接；安装前请保存日程并从托盘退出旧版。安装向导可设置位置、快捷方式和自启动。
- Android 7.0+：`warm-calendar-0.6.0-android.apk`。沿用正式版包名和原签名，可覆盖0.5.0，请勿先卸载。独立预览应用可同时保留，其数据不自动迁入正式版。
- `SHA256SUMS.txt`提供两个安装包的完整性校验值。

## 本版改动

- 自动从本仓库检查正式更新，可关闭自动检查或手动检查；一键下载并打开安装流程，实时显示百分比及下载大小，支持取消、失败重试与缓存复用，安装前校验SHA256。Android仍需系统确认安装。
- 新增“不重复 / 重复日程 / 重复周期”三种模式。周期编辑使用日期列与节点列；支持Day1起计、每周星期记日、停止日期或循环轮数。
- 每个节点可单独设置标题、起止时间、跨日、点型、提醒、节假日、两种颜色与备注；首节点可编辑，新增节点继承上一节点除标题和备注外的设置。
- 七种节假日/周末过滤方式，支持周末遇节假日时的归类；调休上班按工作日处理。组与节点标题组合显示，备注按节点、组分两行，系统提醒同样使用组合内容。
- 日历选中后可删除；点型事项显示为横线与左侧下垂标签，可整体移动和编辑，不提供边界手柄；时间轴支持约两小时分度，可缩至一页容纳全天。
- 修复Windows首次通知状态尚未建立时误报初始化失败；改善节点列表点击反馈、多节点同步容量和分页。

## 验证与范围

56项相关Flutter测试与10项同步服务测试通过；首次通知修复后14项相关用例复查通过。正式构建再通过5项更新模块相关测试及静态分析。独立Windows预览完成安装，测试提醒已核对进入系统通知历史；本机正式版已从0.5.0成功升级至0.6.0。

Android系统横幅、声音、振动及真实自动升级仍需实机验收。同步范围仍为本机/同一局域网；法定放假调休须依已公布数据更新。Windows应用与安装器当前尚无受信任代码签名。
