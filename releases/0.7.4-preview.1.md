# 0.7.4-preview.1

本地独立预览，版本0.7.4-preview.1+15，不发布、不覆盖正式0.7.3。

- 手机日历选中信息使用预留位置，选中后日历不再下移。日历顶部提供删除、编辑、完成；编辑窗不再提供完成勾选。
- 手机首页移除右上新建，下一项日程卡片提供新增日程和查看日程入口。
- 重复日程时间统一使用钟表选择；周期节点起始日固定为左侧所属日，保留结束日及起止时刻编辑。
- 每个普通事项及重复子项独立设置逾期自动完成、完成后自动删除；一次性事项额外支持逾期自动删除。原全局开关移除，旧版已开启的配置迁移到现有事项。
- 右键复制、剪切、粘贴，日程与待办分别保留剪贴板。列表、日历、编辑窗及重复节点支持兼容字段映射。剪切在粘贴保存后才移除来源；重复子项剪切仅作用本次。来源已变更时拒绝剪切保存，保留原项。
- 逐项自动规则纳入备份和设备同步，需两端及内置同步服务均升级本预览版。备份格式5，兼容读取旧备份。

Windows预览使用独立安装目录与数据库；Android包名com.tangtang.warm_calendar.preview。预览数据不自动迁入正式版。不创建桌面快捷方式。

验证包括新增10项用例、重复待办16项、周期表单3项、双端HTTP同步6项、服务兼容1项及静态分析。检查390×844与1280×800渲染，未运行无关全套。Android真机交互和系统通知仍需实际设备验收。

补充：桌面首页、日历、日程页顶部在新建日程旁提供新建待办。独立预览首次运行加入16组示例（标题以「示例·」开头），包含一次性/重复待办、点型/全天/跨日/重叠/多节点日程。可自由编辑删除；已有记录及删除墓碑不会被覆盖，重启不重复加入，正式版不加入。示例以首次打开当天为基准。

布局微调：节点编辑保留日期与时间的两行对齐，所属日固定显示，取消下拉修改入口。
