# 日程表 0.7.0

## 下载与升级

- Windows x64：`warm-calendar-0.7.0-windows-x64-setup.exe`。沿用正式版安装目录、数据和设备连接；保存编辑内容后从托盘退出旧版再安装。
- Android 7.0+：`warm-calendar-0.7.0-android.apk`。保留正式版包名及原签名，可覆盖0.6.0，请勿先卸载。
- 独立预览应用可同时保留，其日程和待办不自动迁入正式版。
- `SHA256SUMS.txt`提供两个安装包的完整性校验。

## 本版改动

- 导航新增“待办”：无固定起止时间的任务列表，支持名称、备注、可选截止时间、未完成/已完成颜色；创建时间固定保存。
- 按创建时间、重要程度或截止时间排序，分别支持正反序。重要程度可在未完成/逾期页桌面开启拖动、手机长按调整，拖至边缘自动滚动并保存顺序。
- 未完成、已完成、已逾期、全部四个子页，支持多选批量删除、完成或恢复未完成。混合完成状态时只允许批量删除。
- 首页增加新增待办、下一项待办、未完成/逾期计数及查看全部弹窗；可快捷完成/删除，点击跳转待办页并动画定位。
- 有截止时间的待办显示为日历点型线标签，可整体拖动改截止、编辑和快捷删除；无截止任务不占日历，不触发日程提醒。
- 设置新增独立“待办过期自动完成”。待办内容、重要顺序和自动完成开关支持设备同步；列表排序偏好各设备独立。
- 日历选中时显示名称和截断备注。修复快速连续点击翻页时目标被动画中途页面覆盖的问题，点击次数准确累计。
- 日程与待办的排序方向箭头增加200毫秒平滑旋转动画。
- 修复Windows升级时后台同步服务路径分隔符不同导致漏检、文件占用而安装失败的问题；安装器仅关闭当前安装目录对应的同步服务。

## 使用与兼容

未完成列表包含逾期；首页下一项取当前排序下首条未完成任务。截止正序时无截止项在末尾，反序严格反转。重要顺序重排保留当前筛选中隐藏任务的位置。

设备同步请将桌面及安卓端一同升级到0.7.0，以获得完整待办能力。新版同步服务兼容旧日程格式，向旧客户端隐藏待办，避免误读为日程。同步范围仍为本机/同一局域网。

相关待办、日历交互、真实HTTP双端同步、提醒和服务端测试通过，包含手机窄屏与大字、边缘拖动、截止时间改期、快速前后翻十页及箭头动画。Android真机操作及系统通知/自动升级仍待实机验收；Windows应用与安装器当前尚无受信任代码签名。
