# 0.7.2

- 新增重复待办：支持单项或多项、每日/每周/每月/自定义循环周期，组内长按调整顺序。
- 每项可独立设置标题、备注、颜色、截止时间与多次提醒；仅展示当前周期，各项可独立完成、删除和调整重要性。
- 普通待办也支持截止前提醒；完成或恢复未完成后显示提示。
- 周期截止天数支持输入和下拉，时刻使用24小时钟表选择，自动校验周期范围，两个控件高度统一。
- 重复日程与待办允许组标题或独立标题留空，但每项至少保留一个标题。

两端同步重复待办时，请同时升级桌面端、安卓端及桌面自带同步服务。正式版保留已有正式数据；独立预览版的数据不会自动迁入。

Windows安装包沿用现有安装位置，默认不创建桌面快捷方式。Android安装包沿用正式包名和签名，可覆盖升级。
