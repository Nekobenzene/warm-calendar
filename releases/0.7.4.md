# 0.7.4

- 手机日历选中日程后保持网格位置不变，顶部统一提供删除、编辑、完成入口。编辑窗不再提供完成勾选。
- 手机首页将新增日程、查看日程放入下一项日程卡片；桌面顶部增加与新建日程同样式的新建待办按钮。
- 重复日程时刻统一采用钟表选择。周期节点保留日期/时间两行对齐，所属日固定显示，不能修改。
- 每个日程、待办及重复子项独立设置逾期自动完成、完成后自动删除；一次性事项可设置逾期自动删除。原全局设置移除，已开启的旧配置迁移到现有事项。
- 增加右键复制、剪切、粘贴。日程和待办分别保留剪贴板；普通事项和重复子项之间映射兼容字段。剪切仅在粘贴保存成功后移除来源；重复子项仅影响本次，取消不会删除原项。
- 新规则随备份和设备同步保存。请同时升级桌面端和安卓端；桌面内置同步服务也随包更新。新备份格式为5，仍可读取旧备份。

Windows安装沿用原目录及正式数据，默认不创建桌面快捷方式；安卓可覆盖升级。预览数据与正式版保持独立，预览示例不会加入正式版。
