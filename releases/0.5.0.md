# 日程表 0.5.0

暖浅色的公历/农历日历与日程工具，支持Windows和Android，日程保存在本机，可通过局域网配对同步。

## 下载

- Windows x64：`warm-calendar-0.5.0-windows-x64-setup.exe`。支持安装目录、快捷方式、自启动和安装后运行；升级前先从托盘退出旧版。
- Android 7.0+：`warm-calendar-0.5.0-android.apk`。沿用原发布签名，可直接覆盖安装，请勿先卸载。
- `SHA256SUMS.txt`提供两个安装包的SHA256校验值。

## 本版功能

- 农历、节气和常见节日离线支持1901—2099年；法定放假调休内置2025、2026年，默认每天联网更新已公布年份并缓存，也支持手动更新。
- 桌面周/月、手机日/周/月视图；七天连续滑动、分度缩放、选中锁、跨日移动与边界调整、半透明拖动预览、重叠分列。
- 重复日程、每日多次、节假日筛选、多个自定义提醒、独立的未完成/完成颜色。
- 手机底部导航，选中详情避让，滚动保持选中；内外层滚动交接和边缘反馈。
- 自定义主题色、背景图片、主界面及侧栏独立毛玻璃与明显程度；重新整理设置分类，失败提示使用独立样式。
- Windows与Android扫码确认配对、设备名称、离线后续传，逾期自动完成设置跨设备同步。
